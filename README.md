# 맛집 블로그 도우미 · macOS V1

Swift + SwiftUI + PhotoKit으로 만든 개인용 앱입니다. macOS 13 이상이 필요합니다.

## 실행

```sh
bash scripts/build-app.sh
open dist/BlogAssistant.app
```

처음 실행한 뒤 **사진 접근 허용**을 누르세요. 실제 권한 확인은 번들된 `.app`으로 실행해야 합니다. `swift run`은 사진 권한 확인용으로 사용하지 마세요.

Xcode에서는 `Package.swift`를 열어 소스를 편집할 수 있습니다. 이 저장소는 Swift Package이며 Xcode 앱 타깃은 아닙니다. 실행 가능한 macOS 앱 번들은 위 스크립트가 생성합니다. 전체 Xcode 없이 Command Line Tools로도 빌드할 수 있습니다.

개인용 로컬 빌드는 기본적으로 ad-hoc 서명합니다. 안정적인 서명 ID가 있다면 `CODE_SIGN_IDENTITY='Apple Development: …' bash scripts/build-app.sh`로 지정하세요. 배포용 공증은 포함하지 않습니다.

## V1 동작

- 버튼으로 PhotoKit 접근 권한 요청
- 시스템 사진 보관함의 이미지 중 촬영일 최신순 최대 300장 조회
- 현재 시간대 기준 촬영일별 그룹, 날짜 없는 사진은 마지막 그룹에 표시
- 각 촬영일 안에서 GPS 거리 100m·직전 사진과 시간 간격 90분을 기준으로 방문 후보를 분리합니다. 거리는 그룹의 첫 유효 GPS 좌표를 기준으로 하므로 이동 경로가 연쇄적으로 한 장소에 합쳐지지 않습니다.
- GPS 없는 사진은 현재 시간상 인접한 후보에 포함하고 위치 불확실 수를 표시합니다. GPS가 전혀 없는 후보는 위치 미확인으로 표시합니다. 날짜 없는 사진은 방문을 추정하지 않습니다.
- 후보는 날짜 및 방문 시간 최신순, 후보 내부 사진은 시간순입니다. 음식점 이름 추론과 수동 병합·분리는 아직 포함하지 않습니다.
- 방문 카드 또는 상세 보기 버튼을 클릭하면 방문 상세 화면에서 사진을 확인하고 음식점명을 입력·저장할 수 있습니다. 빈 이름 저장은 이름 해제입니다.
- 음식점명은 앱의 로컬 UserDefaults에 사진 식별자별로 저장되어 재실행 후에도 유지됩니다. 최근 300장 범위가 바뀌어도 기존 사진이 남아 있으면 이름을 확인할 수 있습니다. 자동 그룹 재계산으로 서로 다른 이름의 사진이 합쳐지면 이름 충돌 안내를 표시합니다.
- SwiftUI `LazyVGrid`로 정사각형 썸네일과 촬영 시간 표시
- iCloud 사진은 필요할 때 썸네일 다운로드, 실패 시 다시 시도
- 사진 보관함 변경 및 앱 재활성화 시 새로고침
- 권한 거부, 기기 정책 제한, 빈 보관함 상태 표시

PhotoKit의 `.readWrite` 접근 레벨을 요청하지만 V1에는 사진 수정·삭제 API 호출이 없습니다. 썸네일 외의 사진 파일 저장, 네이버 연동 및 게시 기능은 포함하지 않습니다.

사진 앱 → 설정 → 일반에서 **시스템 사진 보관함** 설정을 확인하세요. 권한 거부 후에는 시스템 설정 → 개인정보 보호 및 보안 → 사진에서 앱 접근을 허용하고 돌아오세요.

## 구조

- `PhotoLibraryStore.swift`: 권한, 비동기 사진 조회, 촬영일 그룹, 변경 관찰
- `VisitGrouping.swift`: 사진 메타데이터를 이용한 거리·시간 기반 방문 후보 생성
- `VisitNameStore.swift`: 사진 식별자별 음식점명 저장
- `VisitDetailView.swift`: 방문 사진 확인 및 음식점명 편집
- `ContentView.swift`: 권한 안내 및 날짜별 그리드
- `PhotoThumbnail.swift`: 썸네일 요청, iCloud 대응, 화면 이탈 시 요청 취소
- `Resources/Info.plist`: 사진 접근 목적 설명 및 앱 번들 설정
- `Resources/BlogAssistant.entitlements`: App Sandbox 및 사진 보관함 접근
- `scripts/build-app.sh`: release 빌드, 앱 번들 생성 및 코드 서명

## 수동 확인

1. `.app`을 실행하고 권한 요청 전 안내 화면을 확인합니다.
2. 접근을 허용하고 최신 촬영일 순서, 날짜 그룹 및 썸네일을 확인합니다.
3. 앱 권한을 끈 뒤 돌아와 사진이 사라지고 설정 안내가 표시되는지 확인합니다.
4. 사진을 추가·삭제하고 목록이 갱신되는지 확인합니다.
5. iCloud 사진 및 네트워크 연결 실패 시 썸네일 재시도를 확인합니다.
6. 같은 날 다른 장소, 90분 넘게 간격이 벌어진 재방문 및 GPS 없는 사진의 후보 표시를 확인합니다.

그룹화 로직 테스트: `bash scripts/test-grouping.sh` (거리 분리, 시간 경계, GPS 누락, 좌표 이동, 날짜 누락). XCTest 없이 Command Line Tools로 실행합니다.

Notion 참고 페이지는 이후 브라우저에서 확인했습니다. 현재는 사용자와 합의한 사진 조회 및 방문 후보 그룹화 단계까지 구현했습니다.
