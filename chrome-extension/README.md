# 네이버 맛집 참고 글 수집 확장 프로그램

개인용 Chrome Manifest V3 확장 프로그램입니다. 기본 대상은 `bluedog129` 블로그의 **맛집탐방**(카테고리 번호 `65`)입니다.

## 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 저장소의 `chrome-extension` 폴더를 선택합니다.
5. Chrome 확장 프로그램 목록에서 **맛집 블로그 참고 글 수집**을 고정하면 편리합니다.

설치할 때 `blog.naver.com` 페이지 접근과 클립보드 쓰기 권한을 확인하세요. 설치는 사용자가 직접 진행합니다. Chrome Web Store 배포 및 Native Messaging 설정은 필요하지 않습니다.

## 사용

1. 확장 프로그램 아이콘을 누르면 별도 수집 화면이 열립니다. 블로그를 미리 열어둘 필요가 없습니다.
2. **최근 글 최대 5개 가져오기**를 누릅니다. 수집용 탭을 열어 해당 카테고리의 첫 페이지 목록과 본문을 순서대로 읽습니다. 수집용 탭은 작업 후 닫습니다.
3. 결과의 제목·날짜·본문을 확인합니다. 사진 파일 대신 본문 위치에 `[사진]` 표시를 넣습니다.
4. **결과 복사**를 누릅니다. 클립보드 내용은 복사한 참고 글 JSON으로 바뀝니다.
5. Swift 앱의 **참고 글 관리 → 참고 글 붙여넣기 → 확인 후 저장**을 누릅니다.

현재 블로그에서는 맛집탐방 글 1개를 확인했습니다. 글이 5개 미만이면 있는 만큼 사용합니다. 일부 글을 읽지 못하면 이유를 표시하고, 성공한 글만 미리보기·복사합니다. 기존 수집 결과는 실패 시 유지되므로 시각과 제목을 확인하세요.

## 범위와 제한

- 로그인된 Chrome의 네이버 블로그 화면을 이용합니다. 비밀번호·쿠키를 읽거나 앱으로 전달하지 않습니다.
- 네이버 PC 블로그의 카테고리 목록과 SmartEditor 본문 구조를 지원합니다. 구형 에디터·다른 스킨·페이지 변경에는 대응 수정이 필요할 수 있습니다.
- 첫 목록 페이지의 일반 글 중 최대 5개를 읽습니다. 공지 글은 제외합니다. 첫 페이지에 일반 글이 부족하면 다음 페이지까지 수집하지는 않습니다.
- 이미지 파일은 다운로드하지 않습니다. 댓글·사용자 프로필·블로그 관리 정보도 포함하지 않습니다.
- 글 작성·수정·삭제·발행과 AI 서비스 전송을 하지 않습니다. 캡차나 접근 제한을 우회하지 않습니다.
- 수집 화면을 닫으면 수집이 중단될 수 있습니다. 작업 중에는 화면을 열어두세요.
- 설정과 마지막 성공 결과는 확장 프로그램의 `chrome.storage.local`에 저장합니다.

## 검증

JavaScript 문법 검사: `node --check chrome-extension/collector.js`

DOM 추출 검사: 테스트 환경에 jsdom 26을 설치한 뒤 `EXTENSION_TEST_JSDOM=/absolute/path/to/node_modules/jsdom node Tests/extension-checks.mjs`를 실행합니다. jsdom은 테스트 전용이며 확장 프로그램의 실행 의존성이 아닙니다.

Chrome에 설치한 후 카테고리 1개 글 수집, 본문·사진 위치, 결과 복사, Swift 앱 붙여넣기 및 재실행 후 저장 유지까지 확인하세요.
